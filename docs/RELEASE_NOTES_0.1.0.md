# Codex Context X-Ray v0.1.0

The first public release explains Codex's deterministic local context chain
before a session starts.

Highlights:

- Instructions, config, Skills, MCP, hooks, rules, and permissions in one map.
- Repository-only, offline, read-only default.
- Human summary, JSON schema v1, and a self-contained interactive HTML report.
- Fully fictional `codex-xray demo --open` experience.
- Windows, macOS, and Linux support on Python 3.10+.

This is an independent compatibility tool and is not affiliated with OpenAI.
